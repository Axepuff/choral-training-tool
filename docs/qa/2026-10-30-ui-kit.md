# Локальный UI-кит — Issue #54, PR #55

База: `e04a249`. Button → ActionLink → Input → Textarea → Select → Checkbox →
RangeSlider → Message реализованы последовательно, отдельными коммитами в одной
ветке. Перенесены runtime, публичные экраны, Storybook и workflow-прототипы.
Прикладные обработчики, API, аудиодвижок и зависимости не изменены.

## Проверка общего оформления

Перед первым коммитом вес шрифта в общей основе Button временно изменён с 400
на 500. В браузере изменение получили все 50 кнопок шести областей без правок
их экранов: вход (2), редактор (6), библиотека (7), плеер (14), микшер (2),
workflow преподавателя (19). Значение возвращено перед коммитом.

Проверены состояния в stories: обычные/выбранные кнопки, Solo/Mute, busy и disabled,
показ пароля, readOnly и ошибки полей, нативная навигация, checkbox через подпись
и Space, фейдеры обеих ориентаций и сообщения со связью aria-describedby.
Существующие сценарии форм, файлов, dirty guards, поиска и публикации сохранены.

Целевые прогоны после каждого этапа выполнили соответственно 8, 3, 8, 3, 5, 2,
7 и 8 stories вместе с play. Это отдельные пересекающиеся наборы, не сумма
уникальных тестов. Во время каждого прогона проверены 320×640, 360×800, 800×360
и 1280×900 без горизонтального переполнения страницы.

Финально просмотрены снимки входящих в перенос кнопок/полей, библиотеки, плеера,
микшера и прототипов преподавателя/аккаунтов на мобильном и десктопном размерах.
Независимые ревью Standards и Spec обнаружили оставшуюся локальную типографику
и потерянное выделение названий/вкладки. Исправления перенесены в Button и токены;
повторные ревью обоих направлений завершились без незакрытых замечаний.

## Итоговые локальные проверки

Windows: Node 24.11.1, Edge 156.0.4314.50. WSL Ubuntu: Node 24.11.1,
Go 1.27.3 (совпадает с go.mod), Chrome 147.0.7727.116, FFmpeg 6.1.1.

| Проверка | Результат |
| --- | --- |
| typecheck, lint | прошли |
| production build, build-storybook, assemble-pages | прошли |
| Все собранные stories и play в Edge | **74/74**, без пропусков и повторов упавших случаев |
| Node auth в WSL | **15/15**, без пропусков |
| Node audio/MP4 в WSL | **55/55**, без пропусков |
| Node agent-queue в WSL | **44/44**, без пропусков |
| Полный audio browser в Linux Chrome | прошёл: PCM mix, Pause при загрузке/смене loop, включительные такты, метроном, native keyboard, seek, 32 дорожки и ошибки |
| Изолированные runtime/demo build + opt-in Go browser | **2/2**: auth и songs, реальный HTTP/SQLite/FFmpeg, без пропусков |
| Go mod verify, полный Go suite, vet, build | прошли; backup/restore исключён отсутствующим sqlite3 CLI, см. ниже |
| check:mcp | протокол и документация доступны; клиентские docs/preview tools также фактически использованы |
| git diff --check | прошёл |

Сквозной auth прогон подтвердил настоящий вход, logout/reload, сетевые отказы,
блокировку, обязательную смену пароля с явным submit и гостевые маршруты.
Songs прогон подтвердил сохранение/загрузку/ready/reload, частичные ошибки,
конфликты, отмену, поиск, sharing/rotation/revoke, публичное чтение и права.

Node auth runner использует Linux-пути при dynamic import, поэтому его
первоначальный Windows-запуск завершился ошибкой формата URL. Suite выполнен
без изменения runner в WSL. Linux-версии уже зафиксированных native bindings
использованы только в локальном node_modules; package.json и lockfile не менялись.

Обычный Go suite исключает два opt-in browser tests; оба отдельно выполнены выше.
`TestBackupCleanRestore` локально пропущен из-за отсутствия sqlite3 CLI. Конфигурация
backup/restore в этом PR не менялась; CI устанавливает sqlite3 и выполняет тест.
Контейнерные/proxy проверки отдельно не запускались. Статусы remote CI для
опубликованного HEAD находятся в [PR #55](https://github.com/Axepuff/choral-training-tool/pull/55).

Дополнительный полный audio browser в Windows Edge прошёл проверку доступной
Pause при первом Play/seek, затем остановился по timeout ожидания декодирования
после смены активного повтора (`tests/audio-browser.mjs:321`). Тот же полный
набор в Linux Chrome прошёл, включая этот сценарий. Ограничение Edge и ранее
известный underrun из #53 не объявляются исправленными переносом UI-кита.

Эмуляция размеров не является проверкой физических iOS/Android или аппаратного
аудиовыхода. Физические устройства в этом проходе не использовались.
