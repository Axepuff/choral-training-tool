# Ручная проверка повтора и метронома — Issue #12 / PR #38

Владелец 28 октября 2026 подтвердил успешное прохождение всех девяти шагов
на физическом iPhone 16, iOS 26.6.2, Safari. Отдельную версию Safari найти
не удалось; она не установлена и не выводится из версии ОС.

Проверенный HEAD: `e8eebbeb23d0c824d018bacadaef707a7977f0c9`.
Приложение открывалось по HTTPS через Cloudflare Tunnel, с настоящим Go backend,
обработкой FFmpeg и двумя синтетическими звуковыми дорожками. Тестовая песня:
16 секунд, 120 BPM, 4/4, восемь тактов. Публичная ссылка открывалась без входа.
Это runtime плеера, не Storybook или Pages demo.

| Шаг | Действие и ожидаемый результат | Результат владельца |
| --- | --- | --- |
| 1 | Повтор 2–2: один такт, секунды 2–4, подсветка совпадает | OK |
| 2 | Повтор 1–8: вся песня возвращается к началу после 16 секунд | OK |

| 4 | При повторе 3–4 перемотать за пределы и нажать «К началу»: оба действия возвращают к третьему такту | OK |
| 5 | Pause, ожидание, Play: тишина на паузе и продолжение с сохранённой позиции | OK |
| 6 | Нажать Pause во время загрузки после смены диапазона: позднего самостоятельного запуска нет | OK |
| 7 | Включить метроном на несколько повторов и выключить: четыре щелчка на такт, акцент первого, без смещения или двойных щелчков | OK |
| 8 | Ввести 5–2, исправить на 2–3: ошибка временно отключает повтор, исправление восстанавливает его | OK |

Источник — сообщение владельца: «iphone 16 версия сафари не знаю, версия ios
26.6.2», затем «ок» для каждого шага 1–9. Агент отдельно проверил доступность
страницы/API через публичный HTTPS, ответы 206 для Range обеих дорожек и 200
для peaks. Эти HTTP-проверки не заменяют отчёт владельца о слышимом результате.

Ручной блокер `manual_check_required` для этого HEAD устранён. Отчёт не является
новым независимым ревью и сам по себе не разрешает обход проверок контроллера.
Не заявляются Android (отложен в #34), другие устройства/версии браузеров,
32 дорожки, длительное воспроизведение или аппаратные измерения timing.
