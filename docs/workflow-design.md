## План перед реализацией

Палитра из существующих токенов: белая поверхность #FFFFFF, текст #222B40,
вторичный текст #59657B, границы #DCE1EB, акцент #5146C8, его фон #EEECFF.
Текущий Inter/system-ui; заголовок 22px, строки 15px, подписи 13px. Без новых шрифтов.
Выравнивание по левому краю; ширина 820px, одна область отступов, 44px цели.

```text
Песни                         Аккаунты (только admin)
Песни          [Ссылка на список] [+ Песня]
[Поиск                         ] [Порядок]
Название / партии              [Редактировать] [Ссылка]
Статус публикации или следующая необходимая операция

Назад к песням
Ссылка на список
Что услышит ученик: опубликованные готовые песни
[Просмотреть как ученик]       [Создать ссылку]
Полученный адрес               [Копировать]
Ранее выданные ссылки          [Заменить] [Отключить]
```

Проверка плана: общий SaaS dashboard с карточками и счётчиками не помогает
преподавателю выдать материал к репетиции. Вместо него — плотный список и экран
передачи: видимый состав песен, публикация и отдельное управление адресами.
Сохранены исходные цвет, шрифт и компоненты редактора/плеера; выразительность
сосредоточена на статусе и следующем действии, без декоративного оформления.

## Контракты и найденные UX-проблемы

- Текущая SharePanel находится после main с min-height:100dvh: может открываться
  за пределами первого экрана. Кнопка обещает копирование, но открывает управление.
- GET shares не возвращает старые токены. Новый адрес показывается после создания
  или ротации; ротация отключает старый. Копирование не должно молча ротировать.
- Список динамический: все опубликованные и готовые песни одного владельца;
  выбор произвольной подборки/класса потребует отдельного контракта.
- #13 open, зависимости #4/#9 closed. PUT /admin/users/{id}/password уже реализован;
  список/создание/блокировка аккаунтов и их UI ещё относятся к #13.
- Сброс: admin задаёт временный пароль 12–128 Unicode scalar values, передаёт
  вне приложения, сессии отзываются, при входе требуется смена. Email-рассылки нет.
- Админа нельзя случайно потерять: блокировка последнего активного администратора
  запрещена сервером. Прототип только иллюстрирует ограничение.
- Исторические разделы handoff/authentication про отсутствие backend устарели;
  последующие дополнения и текущий код подтверждают настоящие API/плеер.

## Границы макета

Все записи вымышлены, адреса example.invalid, действия живут в памяти Storybook.
Никаких запросов к accounts/songs API и сохранения паролей. Редактор и плеер
переиспользуются; обработка аудио здесь не симулирует успешную конвертацию.
Аккаунты используют email, без выдуманного обязательного имени из отсутствующего API.
Раздел преподавателя и аккаунты доступны отдельными stories; переключение разделов
в админской story не является способом менять роль в настоящем приложении.

Следующая итерация после обсуждения: уточнить состав списка/выдачу ссылок,
затем отдельно интегрировать согласованные UI и серверную часть #13.

## Согласованный вариант на 30 октября 2026

- Ссылка преподавателя открывает все его опубликованные и готовые песни.
  Список обновляется по тому же адресу; ручных подборок и именованных плейлистов нет.

- Карандаш и ссылка находятся отдельной группой справа. Большой кнопки
